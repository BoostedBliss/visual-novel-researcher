## 💖 What is this?
Welcome to the most adorable **Research Visual Novel Studio**! 🧪🎀
This project transforms serious scientific research papers into fun, interactive, and beautiful visual novels. Dive into experiments, talk with cute anime scientists, collect empirical evidence, and level up your scientific certainty!

## 🌟 Super Cool Features
- **🎀 Beautiful Anime Characters**: Dynamic, expressive, and beautifully shaded character sprites that breathe and react!
- **📖 Interactive Storyboard**: Make choices that impact your research path and hypothesis testing.
- **📚 Scientific Codex**: Learn real scientific terms while you play!
- **👗 Character Customization**: Create your very own researcher avatar with fabulous outfits and accessories.
- **📓 Lab Journal**: Keep track of your findings and boost your Empirical Proof Certainty!

## 🚀 Getting Started

Let's get this cute project running on your local machine!

### Prerequisites
Make sure you have Node.js installed! 📦

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/BoostedBliss/visual-novel-researcher.git
   ```
2. Navigate to the project folder:
   ```bash
   cd visual-novel-researcher
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the magical development server:
   ```bash
   npm run dev
   ```

## 🎨 Technologies Used
- **React 19** + **TypeScript** for robust and cute UI components!
- **Vite** for blazing fast builds! 🔥
- **Tailwind CSS** for lovely styling! 💅
- **Framer Motion** for super smooth character animations! 🎬
